# UOJ 界面美化插件 v4 — 通用版 (UOJ Beautify Universal)

**适用于所有 UOJ 及其变体站点**（任意域名，Bootstrap 3 / Bootstrap 4 版式均可），**自动识别、无需配置**。
不改动服务器任何文件，通过浏览器用户脚本（Tampermonkey / Greasemonkey / Violentmonkey）注入样式与增强脚本，即装即用。

## 🔍 通用识别机制

- 脚本匹配所有 `http/https` 站点，但只会在 **UOJ 及变体** 页面上生效：
  - 嗅探特征：`uoj-theme.css` / `uoj.js` / `#form-search-problem` / `.uoj-content` / `.uoj-footer` / `.uoj-username` / `.uoj-honor` / `window.uojHome`
  - document-start 起用 MutationObserver 实时嗅探，命中即在首帧前注入样式；非 UOJ 页面零副作用（不注入样式、不创建任何元素）
- 兼容 **Bootstrap 3 变体**（面板 `.panel`、巨幕 `.well`、BS3 导航/标签页/分页/下拉）与 **Bootstrap 4 变体**（卡片、`.nav-link`、`.page-link`）
- 可在脚本内 `CONFIG` 配置：`hosts`（白名单）/ `forceHosts`（强制启用）/ `disableHosts`（强制禁用）

## 🐛 已修复问题

1. **页面切换时原始界面闪现（白/黑闪一下）**：三重加固——① 样式与主题在 **document-start 立即注入**（解析一开始就生效），MutationObserver 保证插件样式始终排在站点样式之后（级联优先）；② **渐变背景移到 `html` 并同时设置主题色实底 `background-color`**（之前 `background-attachment: fixed` 的多层渐变会被浏览器晚一帧合成，底下透出白色画布；现在即使渐变层晚到，画布也始终是主题色）；③ document-start 时直接在 `documentElement` 上写内联底色作为最终保险。已验证：导航切换的 commit 时刻（最早可绘制帧）画布即为主题色。
2. **题目列表标签看不清**：题目标签徽章原先白字灰底对比度仅 3.26:1（不达标）且外层套了双重胶囊。已改为高对比蓝底深字胶囊（明暗双主题对比度 ≥ 4.5:1，AA 标准），去掉双重胶囊，标题加粗至 600。
3. **表格行悬停时文字看不清**：Bootstrap 4 的 `.table-hover` 在悬停行时会强制把文字色改为深色 `#212529`，暗色模式下即"深字配深底"。已通过 `color` 覆盖修复，明暗双主题悬停行文字均保持可读。

## 🚀 安装方法

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox / Safari 均可）。
2. **方法一（推荐，最可靠）——从 URL 安装**：在浏览器打开 `http://127.0.0.1:8765/install.html`，
   点击页面上「⬇️ 安装 UOJ 美化插件」，Tampermonkey 会弹出安装确认页，点「安装」即可。
   （该地址由本地临时服务器提供，文件在 `uoj-beautify.user.js`。）
3. **方法二——拖拽安装**：把 `uoj-beautify.user.js` 直接拖进浏览器窗口，按提示安装。
4. **方法三——手动粘贴**：Tampermonkey →「添加新脚本」→ **先全选删除编辑器自带的模板头** → 粘贴文件全部内容 → `Ctrl/Cmd+S` 保存。
   > ⚠️ 若粘贴后提示"无法添加脚本"，99% 是因为没删掉编辑器自带的 `==UserScript==` 模板头，导致出现两套脚本头。
5. 打开 **任意 UOJ 站点** 任意页面，右下角出现明暗切换按钮即安装成功。
   > 安装后无需任何配置：自动识别所有 UOJ 及变体；访问普通网站时插件完全不生效。

> 首次进入会弹出「✨  风格美化已启用」提示，仅出现一次。
> 若浏览器不支持 `backdrop-filter`，插件会自动回退为高不透明度玻璃，不影响阅读。

## 🔧 自定义

**默认无需任何配置**。如需要更严格的控制，编辑脚本内 `CONFIG`：

```js
var CONFIG = {
  hosts: [],        // 白名单：非空时仅在这些主机启用（留空 = 自动检测）
  forceHosts: [],   // 强制启用（跳过自动检测，用于特征不完整的 UOJ 变体）
  disableHosts: []  // 强制禁用
};
```

**修改主题色**：脚本顶部 `THEME_CSS` 里的 CSS 变量（`--ub-accent` 蓝、`--ub-frost` 磨砂度、
`--ub-blur` 模糊半径、`--ub-bg` 背景渐变等）即可全局调整，明暗两套变量分别定义在 `:root` 与 `html[data-ub-theme="dark"]` 中。
